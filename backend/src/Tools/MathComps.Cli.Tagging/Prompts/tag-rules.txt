Tag rules:
- Tags should be generally useful; they should apply to many problems.
- Each tag should cleanly fall into exactly one "category". There are four categories:
  - Area: Mathematical fields (Algebra, Geometry, Number Theory, Combinatorics, etc.)
  - Goal: What is the problem asking of us. Examples: Construction Problem, Prove Existence,
    Prove Uniqueness, Count Solutions, Winning Strategy, Drawing Strategy, ...
  - Type: What the problem is about. This is similar to the Area category, except it is
    more in detail. E.g. one could include tags such as 'Absolute Value', 'Inequality',
    'System of Equations', 'Fibonacci Sequence', 'Cryptarithm', 'Circumcircle',
    'LCM', 'Coprime Numbers', 'Periodic Sequence', 'Prime Numbers', 'Two-player Game',
    'Multi-player Game', 'Permutation', ...
  - Technique: Solution methods (Mathematical Induction, Pigeonhole Principle, etc.). These
    should be specific enough that it is clear it's a single technique, not a broad class
    of techniques. E.g. theorems like "Cauchy-Schwarz Inequality" are perfect here
    -- the technique involves proper use of the theorem.
- Use standard English mathematical terminology
- No difficulty levels or competition names
- Not problem-specific
