# Similarity CLI (not in prod yet)

Finds similar math problems using semantic embeddings and metadata matching.

## How It Works

1. **Load Problem Data**: Fetches the source problem's text, solution, tags, and competition info.
2. **Load Embeddings**: Retrieves pre-generated embeddings from the database (generated by the [Embeddings CLI](../MathComps.Cli.Embeddings/README.md)).
3. **Find Candidates**: Filters the database down to a candidate pool. A candidate must sit in the same or an adjacent competition cluster, share at least one tag, and clear a baseline vector-search threshold. Clusters group competitions by difficulty, so a national round sits far from the IMO.
4. **Calculate & Score**: Each candidate is scored on a weighted combination of statement embedding distance, solution embedding distance, tag Jaccard index, and competition cluster distance. A problem with no solution has that weight redistributed among the others.
5. **Store Results**: The final similarity scores are saved to the database.

## Command Reference

### **calculate-similarities**

Calculates similarity scores for problems.

```bash
# Calculate similarities for 100 problems
dotnet run --project backend/src/MathComps.Cli.Similarity -- calculate-similarities -n 100

# Skip problems with existing similarities
dotnet run --project backend/src/MathComps.Cli.Similarity -- calculate-similarities -n 50 --skip-processed
```

- `--count` or `-n`: Number of problems to process.
- `--skip-processed`: Skip problems that already have similarities calculated.

### **interactive**

Starts an interactive session to manually manage similarity relationships.

```bash
dotnet run --project backend/src/MathComps.Cli.Similarity -- interactive
```

- **Commands**: List, remove, or clear similarity relationships.

## Setup

Database connection: see the [main backend README](../../README.md).

Generate embeddings first with the [Embeddings CLI](../MathComps.Cli.Embeddings/README.md) — this tool only reads what is already stored. Run the [Tagging CLI](../MathComps.Cli.Tagging/README.md) too: with no tags, the tag similarity score is 0 for every problem.

Configuration lives in `appsettings.json` under `CalculateSimilarities`:

- **TotalCandidateLimit**: Maximum number of candidates to consider per problem.
- **MinimalSimilarity**: Minimum similarity threshold for candidates.
- **SimilarityWeights**: Weights for statement, solution, tag, and competition similarity.
- **CompetitionClusterMap**: Difficulty scores for each competition (0-10 scale).
- **CompetitionTolerance**: Maximum cluster distance for candidate filtering.
