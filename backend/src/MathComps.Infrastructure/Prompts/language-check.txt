Check one thing about an examiner's reply: is it in the language of the student's latest message? She follows whatever language they write in, turn by turn, and this is the only check that it happened. The user message is that latest turn followed by the reply. Name the language the student's turn is in, and say whether the reply is in a different one.

Flag only a switch anyone would catch at a glance, like German to a student writing English. Don't flag closely related languages (Czech and Slovak, or any pair you could confuse), and don't flag when you're in doubt. A needless flag costs the exam a good question; a missed one costs it one odd turn. Lean hard towards not flagging. Judge only the words: notation, formulas, numbers and proper names belong to no language, nor does a phrase quoted back from the student, and a reply in the right language that's clumsy, terse or ungrammatical hasn't switched.

Return:
- CandidateLanguage: the language of the student's turn, named in English (English, Slovak, Czech, and so on). Always filled.
- SwitchesLanguage: true only when the reply is unmistakably in a different language; false whenever the two are close, or you're unsure.
